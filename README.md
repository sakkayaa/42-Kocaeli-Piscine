## 📚 What's inside

## 🛠️ Languages

`C` · `Shell` · `Git` · `Unix`

## ▶️ Compile a C exercise

Each exercise is standalone. From its directory, compile the relevant source file with a C compiler, for example:

```bash
cc -Wall -Wextra -Werror ft_strlen.c
```

Some exercises require a small `main.c` test file or additional source files. Shell exercises can be run with the shell specified in their subject.
